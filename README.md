# Participants’ Hub — KVS Ahmedabad Music Teachers CPD

**Organising institute:** Zonal Institute of Education & Training (ZIET), Mumbai  
**Target group:** KV Music Teachers, KVS Ahmedabad Region  
**Training dates:** 2–6 November 2026  
**Duration:** Five days

## About
A digital participant directory for the Mass Saturation CPD Training Programme for KV Music Teachers, designed to support participant lookup and workshop coordination.

## Features
- Search by participant name, Hindi name, designation, or school.
- Filter the directory by school.
- Download the filtered list as CSV.
- Print the directory or save it as PDF.
- Responsive design for mobile and desktop.
- Hindi and English participant names where available.

## Files
- `index.html` — standalone participant hub; the directory and its search/filter/export functions run in the browser.

## Run locally
Download `index.html` and open it in a modern web browser. No build step or server is required.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for deployment and use the URL shown in the Pages settings.

If this repository is private, GitHub Pages availability depends on your GitHub plan. Make the repository public if you want a publicly accessible hub and your plan does not support Pages for private repositories.

## Responsible use
Verify participant names and school spellings against the official list. Avoid publishing personal phone numbers, email addresses, or other sensitive information.
